# Security Policy

## Supported Versions

White Mode Buttons is currently provided as a small Firefox/WebExtension add-on.

| Version | Supported |
| ------- | --------- |
| 1.0.0   | ✅ |
| older versions | ❌ |

## Reporting a Vulnerability

If you find a security issue in White Mode Buttons, please report it privately through GitHub Security Advisories.

Please do not create a public issue for security vulnerabilities.

Project: White Mode Buttons  
Repository: https://github.com/Germanen/white-mode-buttons  
Maintainer: Dave Soysal (GermanusTV)

## Scope

Security reports should focus on issues related to:

- browser extension behavior
- permissions
- injected CSS or JavaScript
- unsafe handling of data
- unexpected access to tabs or web pages

White Mode Buttons is designed as a small accessibility and visibility add-on for Firefox.
